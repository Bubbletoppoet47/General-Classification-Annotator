2026-10-08 - first shared copy

What it is
- The annotator only annotates and publishes. Training (collecting everyone's data, validation sets, the Train window)
  is a separate program and is not in this folder.

Menus
- File:   Import Gimble Session, Import Video, Insert Assist Model, Insert Scratch Model, Publish to shared folder,
          Import data to edit, Shared folder location, Models folder location, Exit.
- Edit:   Classes, Hotkeys, My name, AI confidence, Toggle theme.
- Manage: Sessions (with Access to other people's data), Sync Deleted Files.
- The toolbar keeps the LiDAR dots / pick-distance checkbox, the AI model box and Confirm Image
  ("Confirm As-Is" is now called "Confirm Image").

Sharing your annotations
- First time: File > My name (asked once), then File > Shared folder location and pick the shared folder.
- File > Publish to shared folder copies your annotated images (with boxes, distances and LiDAR depth) into your own
  folder inside the shared folder. It looks at what is really in your folder and only adds what is missing or changed,
  so an empty folder gets everything. Nothing is ever deleted from it.
- Only annotated images are shared. Videos, sessions and unannotated frames stay on your computer.
- File > Import data to edit lets you bring in someone else's set to fix it. Your fix goes into your own folder and the
  image keeps the original annotator's name. If two people edit the same image, the newest edit wins automatically.
- Whether something is for training or validation is chosen in the training program, not here.

AI models
- File > Models folder location: pick the shared Models folder (it has Assist and Scratch folders inside).
- File > Insert Assist Model / Insert Scratch Model: the newest version of each size is listed first, older versions in
  a nested list. Clicking one copies it to your computer, adds it to the AI model box and loads it.
- Hotkeys can be changed in Edit > Hotkeys.

Setup
- Install the packages once:  pip install -r requirements.txt
